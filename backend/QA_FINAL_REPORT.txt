🎓 LESSONS LEARNED
════════════════════════════════════════════════════════════════════════════════

1. Transaction Pattern: Using atomic findOneAndUpdate() prevents race conditions
   and bypasses schema validation where needed. This pattern is critical for
   ERP postings.

2. FIFO Complexity: Multi-batch FIFO requires careful loop control to handle
   partial consumption from multiple batches. Simple "take one batch" logic
   fails when qty spans batches.

3. Data Validation: Stock validation MUST happen before any Stock Ledger entry
   is created. Allowing negative stock corrupts entire financial system.

4. Error Handling: Missing validation in one place (FIFO) cascades to break
   downstream tests. Comprehensive validation layers essential.

5. Journal Line Format: Core Engine expects specific journal line structure
   with accountId/debit/credit. Mismatches cause subtle failures.
