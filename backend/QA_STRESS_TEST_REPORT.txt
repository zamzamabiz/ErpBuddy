Problem:

    status: { type: String, enum: ['Draft', 'Posted', 'Cancelled'], default: 'Draft' }

The enum does NOT include 'Posting', causing validation error:
    "status: `Posting` is not a valid enum value for path `status`"

Root Cause:
Unlike the Purchase service which uses atomic findOneAndUpdate() to bypass validation,
the Sales service uses save() which validates the full object against the schema.
