## 🔧 What Was Fixed

### BUG #1: Negative Stock Allowed ❌ → ✅

**Before:**
```
Sale 100 units (only 50 available)
→ System allowed it!
→ Created balance: -50 ❌ WRONG
```

**After:**
```
Sale 100 units (only 50 available)  
→ System validates upfront ✅
→ Error thrown: "Insufficient stock: 50 available, 100 requested"
→ Balance protected: 50 ✅ CORRECT
```

**Test 5 Result:** ✅ Now **correctly rejects** the sale

---

### BUG #2: Multi-Batch FIFO Incorrect ❌ → ✅

**Before:**
```
Batch 1: 1000@$10 (50 remaining)
Batch 2: 500@$20 (newly added)

Sale 100 units
→ COGS = $1000 ❌ WRONG
→ Only consumed from Batch 1
→ Ignored Batch 2 entirely
```

**After:**
```
Batch 1: 1000@$10 (50 remaining)
Batch 2: 500@$20 (newly added)

Sale 100 units (FIFO order)
→ Take 50 from Batch 1 @ $10 = $500
→ Take 50 from Batch 2 @ $20 = $1000
→ COGS = $1500 ✅ CORRECT
→ Unit Cost = $15 (weighted average)
```

**Test 6 Result:** ✅ Now **correctly calculates** multi-batch COGS
